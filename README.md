# DevSupport

Plateforme de support informatique (tickets + temps réel).
Stack : React · Node.js · Express · MongoDB · Socket.IO · JWT

## Structure
- `server/` — API REST + Socket.IO
- `client/` — Front React (à venir)

## Démarrage
```bash
npm run install:all
cp server/.env.example server/.env   # puis remplir
npm run dev:server
